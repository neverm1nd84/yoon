## 잠정 추천
1. PSA 분당 (1순위): 영유 경험 없는 7세에게 가장 안전한 유형. 정원 16명, 한국인 부담임, 정자동.
2. BEK 분당 (2순위): 놀이·테마 중심, 한국어 지원. 학비와 중국어 필수 과목 감수 가능 여부가 관건.
3. 마운트피스가 (비교용): 거리 가장 가까울 수 있음.
4. 폴리: 신입 전용 반이 있고 윤이가 읽기·쓰기를 어느 정도 한다면 재검토. 그 전까지는 후순위.

## BEK 분당 학부모 후기 (카페 '분따' 게시글, 작성자 찬이맘v정자동, 작성일 미확인)
> 전부 **개인 의견**이며 글 한 편 기준. 사용자가 본문을 붙여넣어 제공. 아래 블로그 2건은 `blog.naver.com` 접근 차단으로 읽지 못함: https://blog.naver.com/mapiajjang/223909689304 , https://blog.naver.com/fascinate815/224090137208
- 대상 4~7세, 내년 초등반 오픈 예정이라고 안내받음. 수강료는 "3분기 결제로 조금씩 다름"이라고만 하고 금액 없음.
- 시설: 상가지만 한 층 전체를 써서 반이 넓고 체육 강당이 큼. 단독 건물이 아닌 점은 아쉬움.
- 교사: 원어민 + 이중언어 교사, 모두 교육학 전공. 이중언어 교사도 수업은 영어로만 진행하고, 학부모와는 한국어로 소통(주로 메일, 전화 상담은 따로 없음, 픽업 때 짧은 대화, 필요하면 먼저 전화, PTC 정기).
- 수업: 교재보다 활동 중심, 듣기·말하기 많음, "한국 유치원 프로그램을 영어로 하는 느낌", 영유보다 '학교' 분위기. 5세까지 숙제 거의 없고 6세부터 라이팅 시작(강하지 않음).
- 활동: 거의 매달 이벤트(International Day 등). 중국어는 중국인 교사 상주, 음악은 정식 수업, 1:1 레슨(보컬·바이올린) 선택 가능. 중국어 외 수업은 모두 영어.
- 오래된 곳이고 형제도 계속 보내는 편. 정보와 후기가 적다고 함.
- 한계: 작성자 자녀가 5~6세로 보여 **7세 신입·영유 경험 없는 아이 적응 사례는 없음**. 학비·셔틀·하원 시간 정보 없음. 후기 한 건이라 일반화 불가.
