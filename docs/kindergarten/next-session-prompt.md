이번 세션 할 일:
1. 브라우저 도구(내장 브라우저 또는 Chrome 연동)로 이 네이버 카페 게시판을 심층 조사해줘:

   (이미 내가 로그인해 둠. 읽기만 하고 댓글/글쓰기/좋아요 등은 절대 하지 마. 로그인 정보 요구되면 멈추고 알려줘.)

작업 후 변경사항은 커밋하고 현재 브랜치에 푸시해줘. PR은 만들지 마.
