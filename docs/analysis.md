# 윤이 영어유치원 선택 분석 (1차, 2026-10-07)

## 배경
- 윤이: 2021년생, 내년(2027) 7세. 현재 일반유치원(누리과정). 영어공부는 꾸준히 했으나 영유 경험 없음.
- 거주: 분당 미금역. 거리 중요, 분당 안에서만. '제이리'는 제외.
- 관심 후보: 폴리, BEK, PSA. 아내와 웹으로 공유하며 status 업데이트 예정.
- 핵심 기준: 1년차(신입) 반 개설 여부, 아니면 진급반이라도 적응 가능한지.

> 주의: 아래 학비·정원은 포털/요약 글 기준이며 미검증. 공식 사이트(bek.co.kr 등)와 네이버 카페는 클라우드 환경에서 접속 불가해 직접 확인하지 못함.

## 환경 변화 (규제)
- 학원법 개정: '4세·7세 고시'(유아 대상 레벨테스트) 금지, 2026년 10월 시행 보도. 공인시험 성적 제출·구술면접 등 우회 사례 있음 -> 입학 절차 확인 필요.
- 유아 인지교습 하루 3시간/주 15시간 제한. 학습식 원이 영향 큼(이미 3시간 내 운영하는 곳도 많음).
- 7세 신입은 대개 기존 진급반 합류 -> "신입반 유무 / 진급반 적응 지원"이 최우선 질문.

## 분류 (카페 글 기준, 사용자 제공 이미지)
- 학습식: 제이리, 파커, FTK, FIS, 베키, 폴리, BIS
- 절충식(활동 다양한 학습식): 라이즈, 마운트피스가, PSA, 레드웨건, ECC, ACA, 레지오elc, 리틀타츠 등
- 테마수업 중심 놀이-절충식: 틸아임, KDLP, 메이플베어, BEK

## 잠정 추천
1. PSA 분당 (1순위): 영유 경험 없는 7세에게 가장 안전한 유형. 정원 16명, 한국인 부담임, 정자동.
2. BEK 분당 (2순위): 놀이·테마 중심, 한국어 지원. 학비와 중국어 필수 과목 감수 가능 여부가 관건.
3. 마운트피스가 (비교용): 거리 가장 가까울 수 있음.
4. 폴리: 신입 전용 반이 있고 윤이가 읽기·쓰기를 어느 정도 한다면 재검토. 그 전까지는 후순위.

## 상담 때 질문
- 2027년 7세 신입반이 열리나? 신입이 진급반에 들어가면 적응 지원은?
- 입학 절차는? 레벨테스트 금지 후 어떻게 바뀌었나?
- 하루 인지교습 시간, 한국어 사용 시 벌점 여부
- 월 총비용(교재·급식·셔틀·특활 포함)
- 미금역 방면 셔틀, 하원 시간
- 졸업 후 초등 영어 연계
